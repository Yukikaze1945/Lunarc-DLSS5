# Issue #1: native preview packaging and environment localization

Date: 2026-11-06.

## Report and cause

The reporter confirmed that version 1.4.0 resolved the original blank startup window. Their later screenshot reports a missing `gpu_native_presenter.dll` while opening the workbench preview. The Electron resource filter explicitly excluded that library, the shared native manifest did not list it, and the release packaging check mirrored the exclusion. This allowed a package without its required preview presenter to pass the previous checks.

The second screenshot also shows untranslated environment overview text in English mode. Labels and readiness messages were missing from the catalogs. Missing-dependency lists combine translated UI text with dependency labels, so translating only the whole string left the embedded Chinese labels unchanged.

## Changes

- Include the project-built native presenter in Electron resources and the shared native binary manifest.
- Reject builds missing that DLL; require it in the packaged-resource hash check.
- Check its exported open entrypoint in environment diagnostics and expose GPU preview dependency status.
- Translate environment labels, status templates and actions in English, Japanese and Russian. Translate composed dependency labels explicitly, while retaining paths, technical names and raw diagnostic payloads.
- Isolate environment unit tests from the developer's selected runtime cache.

## Verification

- 26 targeted Python tests and 12 Node tests pass in the issue-only public checkout.
- TypeScript/Vite/Electron builds and Electron directory packaging pass.
- The packaged presenter is 183,808 bytes and matches the issue branch binary: SHA-256 `33b82a8e516b9a47c22c58f6ba44d11a807667dc64f60e89a12fc345b6d8dfb5`.
- The DLL loads from the packaged native directory and exports error/open/config/frame/stats/close/freeze. No GPU session was opened.
- No GPU render, reporter-machine reproduction, new Setup release, or full application interaction regression was performed. The issue should remain open pending the reporter's confirmation.

Missing optional DLAA, RTX VSR and NVIDIA VFG runtimes are separate from the required presenter. They are needed only when their corresponding stages are used.
