# Lunarc 1.4.0

Released 2026-10-20.

## Highlights

- Added DLSSNR A/B model selection, with independent settings for additional NR layers. Runtime import now selects the imported library automatically. Unrecognized or unsigned third-party builds are allowed and labeled, while file format, expected hashes and cache integrity are still checked. No model DLL is bundled.
- Added ProRes 422 10-bit input and ProRes 422 HQ MOV export. Rendering uses the GPU; ProRes output is encoded on the CPU.
- Added HEIF image import/export and JPEG XR input, with format and precision checks. Hold Ctrl to select multiple image output formats; exports run in selection order.
- Added single-frame rendering and image export for video input. Simplified advanced settings according to image or video input.
- Improved native-call timeout detection and backend recovery, including queue checkpoint checks before restart. Rendering failures do not silently restart or retry an export.
- Fixed preview, export-option normalization and source-precision validation issues. Updated the four-language documentation and simplified the public website.

## Download

Use **Lunarc-1.4.0-x64-Setup.exe** from the [v1.4.0 release](https://github.com/Yukikaze1945/Lunarc-DLSS5/releases/tag/v1.4.0). The base runtime and optional processing components are installed separately. Existing compatible components and user settings are retained.

## Verification

The installer was built and its first-start UI and packaged resource hashes were checked. Targeted checks: 102 Python tests and 85 Node tests passed. No GPU rendering or new-runtime compatibility benchmark was performed for this release. See [release verification](../validation/release-1.4.0.md).
