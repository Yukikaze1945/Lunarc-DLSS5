# Lunarc 1.4.1

Released 2026-11-06.

## Fixes

- Fixed the missing native GPU preview presenter in the Windows installer. This addresses the preview failure reported in [issue #1](https://github.com/Yukikaze1945/Lunarc-DLSS5/issues/1) after upgrading to 1.4.0. The presenter is now required by packaging checks and covered by environment diagnostics.
- Fixed untranslated environment labels, readiness messages, missing-dependency lists and actions in English, Japanese and Russian. Paths, technical names and original diagnostic payloads remain unchanged.

## Update

In **About → Software updates**, check for updates and download 1.4.1. Exit Lunarc, then run **Lunarc-1.4.1-x64-Setup.exe** from the update download directory. Compatible installed components and user settings are retained.

The installer and supporting update metadata are also available from the [v1.4.1 release](https://github.com/Yukikaze1945/Lunarc-DLSS5/releases/tag/v1.4.1). DLSSNR and other NVIDIA model runtimes remain separate.

## Verification

See the [release validation record](../validation/release-1.4.1.md). No GPU rendering regression or reproduction on the reporter's machine was performed for this patch.
