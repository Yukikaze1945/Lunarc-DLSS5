# 原生 GPU 挂起恢复

日期：2026-10-18。范围：Lunarc 自己启动的后端进程。

## 决定

原生调用继续在原来的资源所有者线程执行。独立 Python 监测线程仅记录超时、熔断新任务并保存队列，不执行 GPU close/reset，也不尝试杀死 Python 工作线程。Electron 在确认队列保存后结束旧后端进程树，等待其退出及端口释放，再启动一个新后端。

预览和普通导出阶段使用 300 秒期限；图片分步处理每项 600 秒；编码器排空 180 秒；资源关闭 90 秒。阶段完成后更新期限。取消导出后另设 30 秒退出期限，新的处理阶段不能延长它。图片格式编码和视频封装不参加 GPU 超时判断，继续使用各自原有的子进程超时及取消规则。

健康接口仅访问 Python 状态和已缓存的显存数据，不等待 GPU 锁。它提供当前操作、阶段、已用时间、剩余时间及队列保存状态。如果该接口也失去响应，Electron 只在此前确认了自己拥有的 PID、进行中的原生操作和有效队列存档时，于该阶段期限再加 15 秒后请求恢复。单纯 HTTP 失败、空闲或外部启动的后端不触发此规则。

恢复沿用每次故障只尝试一次、60 秒内重复故障停止自动恢复的限制。运行中的导出恢复为中断失败，可手动重试；其他排队任务保持原样，不自动重复导出或覆盖文件。没有桌面主进程监督的独立后端只会熔断，需要外部监督者或手动重启。

## 取舍与验证

进程退出可以回收线程无法安全释放的原生资源，但会丢失 GPU 预览会话；桌面端继续恢复素材和参数，预览仍需用户主动启动。若某个合法阶段超过上述保守期限，也会被中断，不据显存用量直接判定挂起。若队列存档失败，自动重启保持禁用。

通过事件阻塞、可控时钟、队列重载和主进程监督逻辑测试验证边界，不通过制造真实 GPU 死锁或驱动重置来验收。
