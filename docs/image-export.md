# 图片加载与导出

视频与图片的完整格式表见[媒体格式](media-formats.md)。

将 PNG、JPEG、BMP、WebP、TIFF、AVIF、HEIC／HEIF、JXL 或 JXR（JPEG XR）图片拖入工作台，或通过“导入”选择。常见 8-bit SDR 图片直接解码为 RGBA 并上传到 GPU；带完整 BT.2020／PQ 声明的 HDR AVIF 与 scRGB fixed/float HDR JXR 解码为线性 FP16。JXL、HEIC／HEIF 输入仅接受 8-bit SDR；其它高位深或 HDR 输入会明确拒绝，不自动降为 8-bit。16-bit／32-bit 整数 JXR 也会被拒绝。

工作台与图片导出页均支持 Alt＋滚轮缩放（25%–800%）、左键拖动画面。放大后，不按 Alt 的滚轮上下移动图片；图片未超出画布时保留页面正常滚动。双击恢复适配。工作台保留完整原图和处理图，在前端完成缩放、移动与中央对比，查看位置不改变导出尺寸，也不重新运行模型。

图片可以使用 DLSSNR、DLAA、RTX VSR、IllustrationJaNai V3、AnimeSharp V4 和 TrueHDR，以及现有的多层 NR 处理。静态图片使用零运动输入，不计算帧间光流或时间稳定，不执行 VFG。播放进度与选区控件在图片模式下隐藏。

点击右上角“导出图片”，设置格式、保存位置和文件名：

| 格式 | 保存选项 |
| --- | --- |
| PNG | 无损编码，支持保留透明度 |
| JPEG | 质量 1–100；不透明，原图透明区域填充白色 |
| WebP | 质量 1–100；100 为无损编码，支持保留透明度 |
| AVIF | AV1 图片；SDR 质量 1–100、4:4:4，支持透明度；HDR 为 10-bit BT.2020／PQ 4:4:4，可带透明度 |
| HEIC（`.heic`） | HEVC-in-HEIF；SDR 质量 1–100、4:4:4，支持透明度；HDR 为 10-bit BT.2020／PQ 4:4:4，可带透明度 |
| HEIF（`.heif`） | HEIC 使用同一 HEVC-in-HEIF 编码器与选项，独立格式按钮和 `.heif` 扩展名 |
| UHDR JPEG | `.jpg` SDR 基图加 HDR 增益图；兼容查看器可恢复 HDR，不支持透明度 |
| JXL | SDR 8-bit sRGB 或 HDR 16-bit BT.2020／PQ RGB，支持透明度；质量 100 为无损编码 |

输出采用当前工作台的渲染参数和整条渲染链的输出尺寸。可导出当前完整分辨率渲染缓存，或按当前设置重渲染；不会保存预览缩略图。必要的边缘补齐会在输出时裁掉；透明度从原图恢复，缩放时同步缩放透明度。

嵌入的 ICC 配置会在输入时转换为 sRGB；JPEG 的 EXIF 方向用于纠正图片方向。普通 SDR 导出写入 sRGB ICC 配置。TrueHDR 渲染结果可按 SDR 格式经固定显示映射保存，也可按 HDR 格式保存为 PQ HDR；HDR 保存不经过 SDR 显示映射。

PNG、JPEG、WebP 和常见 TIFF／BMP 输入及输出为 8-bit SDR。AVIF 与 JXR 可作为 HDR 输入；JXL、HEIC／HEIF 高位深或 HDR 输入当前不支持。图片输出可选择 SDR 或 HDR；HDR 输出格式为 AVIF、HEIC、HEIF、UHDR JPEG 和 JXL。动画图片仅处理第一帧。Ctrl 点击格式可按顺序多选保存；一次重渲染的结果可供后续格式复用。禁止覆盖原图片；默认不覆盖已有目标文件，临时文件成功编码后才发布结果。

SDR AVIF 使用 [Pillow AVIF 编码器](https://pillow.readthedocs.io/en/stable/handbook/image-file-formats.html#avif)，HDR AVIF 使用 CPU libaom；HEIC／HEIF 使用 [pillow-heif](https://pillow-heif.readthedocs.io/en/stable/saving-images.html)。源码依赖与运行环境构建清单包含 Pillow ≥11.3、pillow-heif 1.8.1。格式按钮按后端实际编码能力启用；缺少编码器时不通过改扩展名或换格式冒充成功。

源码版改动生效需要退出工作台后运行 `run_gui.bat`。安装版仍需要后续重新构建，本轮没有发布新的安装包。

## 图片放大模型与多层 VSR

图片模式的渲染顺序中可以添加两个模型磁贴，与 DLSSNR／DLAA／VSR 一样排序、停用和移除：

- IllustrationJaNai V3：4× DAT2，去噪／细节版本。作者发布了多种网络，本次磁贴明确使用 DAT2。
- AnimeSharp V4：2× RCAN 标准版。
- 默认整图、FP32 推理。分块 128／256／512 为可选项，带 32 像素输入边缘上下文；分块可能改变全图上下文与边缘结果，不自动启用或在显存不足时偷偷改用分块。
- 当前只接收 SDR 图片，请放在 TrueHDR 前。各模型按自身倍率放大；透明度在保存时从原图恢复。整图处理大图片仍可能超出可用显存。

磁贴提供官方来源下载和本地 `.safetensors`／`.pth` 导入，权重放在用户数据目录的 `image-models` 缓存。官方压缩包／文件验证固定 SHA-256 和长度；本地导入记录 SHA-256，加载时复验，且只用安全张量或 `weights_only=True` 加载。未安装、架构／倍率不匹配和损坏文件明确拒绝。下载完成或重新导入后刷新预览。

安装版先在组件管理安装 **AI 模型运行环境**（与 RAFT 共用 PyTorch／CUDA），再安装 **图片模型组件**。模型权重单独下载，不包含在安装包中。模型许可与 Lunarc 源码许可分别适用，请查看 [IllustrationJaNai 作者发布页](https://github.com/the-database/MangaJaNai/releases/tag/3.0.0) 和 [AnimeSharp V4 作者模型页](https://huggingface.co/Kim2091/2x-AnimeSharpV4)。

RTX VSR 可重复添加，每张磁贴独立保存模式、档位、强度、倍率／分辨率和开关。每层接收上一层的输出，显示与导出尺寸按顺序累计。旧预设中的单层 `vsr` 和全局 VSR 参数继续有效。

## 释放预览显存

工作台预览工具栏提供 **释放预览显存**。点击后暂停播放、等当前帧完成，释放预览链、解码与显示资源、RAFT 权重及 PyTorch 保留缓存；参数和磁盘上的模型文件不删除。释放后调整参数不会自动重载，点击 **恢复预览** 才重新加载。恢复后首次预览可能更慢。

显存紧张且更换模型、尺寸、来源或链路时，程序会先完整释放旧预览，再按原参数加载新预览；普通后处理调整继续热更新。导出期间不能用此按钮释放导出资源。预览保持暂停时也可明确导出图片，完成后释放这次操作加载的预览模型。

自动保护依据当时可读取的显存预算，不降低精度、分辨率或自动启用分块。重新加载时会拦截已知工作图像缓冲都放不下的请求；SDK 内部模型和瞬时工作区无法完整预估，保护不能保证所有组合都不再显存不足。资源关闭失败仍会停止新 GPU 操作并进入原有恢复流程。

## 视频单帧

载入视频后，在工作台的“渲染方式”选择“单帧渲染”，定位到需要的帧并点击“渲染一帧”。完成后点击“导出当前帧”，可直接使用完整分辨率缓存保存图片；切换帧号后须重新渲染，不会误用其他帧的缓存。单帧不执行 VFG，渲染完成后释放模型资源；HDR 结果保留 FP16，可选择已有的 HDR 图片格式保存。

高级设置按素材类型显示：图片隐藏光流、时域和视频导出选项；运行库路径覆盖位于“软件设置”，画面风格使用渲染链上方的控件。

按住 Ctrl 点击格式按钮可多选，普通点击恢复单选。程序按选择顺序逐个保存；选择重新渲染时只渲染一次，后续格式复用这份结果，不并行加载模型。中途失败时停止后续格式，并保留已成功保存的文件。
